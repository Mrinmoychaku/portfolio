Flagship Production Platform

Yoga Scoring System (YSS)

A comprehensive real-time web-based judging and scoring platform built for competitive yoga tournaments. Enables a panel of judges to evaluate competitors seamlessly from smartphones while broadcasting instant, unbiased scores to screens and audiences.

  • Real-Time Smartphone Judging: Judges log into private responsive portals on their phones to submit scores for each asana as competitors perform.
  • Automated Trimmed-Average Algorithm: Eliminates bias by automatically discarding the highest and lowest scores given for each asana, computing the fair cumulative total instantly.
  • Live Leaderboard & Projection Display: Audience and participants view scores, standings, and rank updates live on large screens without delay.
  • Full-Stack Architecture: Built using Python, HTML5, CSS3, JavaScript, and relational database management to ensure flawless runtime stability.
