## 🚀 How to Run Locally (কীভাবে কম্পিউটারে চালু করবেন)

1. **Directly in Browser**:
   - Simply double click on `index.html` to open it in Google Chrome, Microsoft Edge, or any web browser.
2. **Using VS Code Live Server**:
   - Right click on `index.html` and click **"Open with Live Server"**.
3. **Using Python Local Server**:
   - Open PowerShell or Terminal in this folder and run:
     ```bash
     python -m http.server 8000
     ```
   - Then open `http://localhost:8000` in your browser.

## 🌐 How to Deploy for Free (কীভাবে ইন্টারনেটে লাইভ করবেন)

### Option 1: GitHub Pages (Recommended)
1. Push this folder to a GitHub repository (e.g., `portfolio` or `<your-username>.github.io`).
2. Go to repository **Settings** -> **Pages**.
3. Select `Branch: main` and `/ (root)` folder, then click **Save**.
4. Your site will be live at `https://<your-username>.github.io/portfolio/` within 1 minute!

### Option 2: Vercel or Netlify
- Drag and drop this folder directly into [Netlify Drop](https://app.netlify.com/drop) or import from GitHub on [Vercel](https://vercel.com) for instant global deployment.
